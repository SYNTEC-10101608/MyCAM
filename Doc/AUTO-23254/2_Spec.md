# 2. 規格提案

規則的最終版本寫在專案指引 `.github/instructions/ui-style.instructions.md`（以下稱「指引」）；本章說明每項規格做了什麼、
對應哪個需求（[1_Goal.md](1_Goal.md)），數值與 API 以程式為準。

## 2.1 操作規格

使用者看得到的變化。

| 編號 | 規格 | 需求 |
| --- | --- | --- |
| S1 | **視覺主題**：所有畫面改為同一套淺色主題（色票、字型、圓角按鈕、白底卡片與標題列）；字族依介面語系（zh-TW 正黑、zh-CN 雅黑、其他 Segoe UI） | R1 |
| S2 | **對話框外框與位置**：所有對話框為工具視窗，不可拖曳改大小、不出現在工作列與 Alt+Tab；開啟時置中，橫式在整個主視窗、直式在上半部 CAM 區域；只改高度時位置不動 | R1 |
| S3 | **對話框版面**：區塊一律是卡片，卡片垂直排列等寬；按鈕列主要動作在最右、取消在其左、輔助動作靠左；確定鍵統一為「確定」（有明確動作的按鈕保留原文字）；精靈分展開式與切換式兩型 | R1 |
| S4 | **按鈕種類**：對話框以藍色實心表示完成這一步的動作、紅框紅字表示可能遺失資料的動作；CNC 加工鈕開始 / 暫停與繼續 / 停止為淡綠 / 淡橘 / 淡紅；停用一律灰色 | R1 |
| S5 | **數值輸入**：所有數值欄位為同一種數值框：非法或超出範圍的輸入回復最新的合法值，滾輪與上下鍵一次一個增量並停在上下限，清空後回復；只顯示、從不輸入的座標改為文字標籤 | R1、R4 |
| S6 | **主視窗**：工具列圖示統一為透明背景（功能工具列 40×40、其他 20×20），新增類圖示右下角加「+」；區域之間與 CNC 卡片之間一律相距 8；橫式訊息區橫跨底部時日誌在左、警報在右，訊息區是一欄時上下排列；加工頁監控卡片與 3D 畫布左右對齊 | R1 |
| S7 | **CNC 面板**：區塊標題改為卡片標題；面板隨主視窗大小縮放時，卡片間距與標題列不縮放 | R1 |

## 2.2 實作規格

| 編號 | 規格 | 需求 |
| --- | --- | --- |
| S8 | **外觀與行為分層**：三類畫面各有一個只管外觀的基底（`MainWindowBase`、`PanelBase`、`DialogBase`）；行為基底 `FormBase`、`EditDialogBase<T>` 疊在 `DialogBase` 之上、原封保留。`Show` / `ShowDialog` 呼叫點不變 | R2、R4 |
| S9 | **主題 token**：`CommonUI.Theme` 的 `ThemeColors`、`ThemeFonts`、`ThemeMetrics` 是顏色、字型、尺寸的唯一來源；文字以 `TextRole` 表達；字族在建立任何畫面前由 `MyApp.Initialize()` 決定；資料色為具名常數並登錄 | R1、R2 |
| S10 | **`CommonUI` 唯一元件來源**：控制項與共用工具依 `Theme`、`Controls`、`Forms`、`Layout`、`Language` 五類分資料夾，資料夾即 namespace；`MyCAM`、`CncUI` 原有的自訂控制項移入或以新元件取代後刪除 | R2、R3 |
| S11 | **Designer 如實呈現**：外觀屬性在基底與元件建構子設定並標為不序列化；所有畫面 `AutoScaleMode = None`；`InitializeComponent()` 之後不寫外觀程式 | R5 |
| S12 | **版面機制**：對話框為 Designer 固定座標，執行時只透過 `SectionStack`（補位、按鈕列、換頁）；嵌入式面板以 `ResponsiveLayout` 縮放；主視窗以 `MainLayout` 純計算區域（`Calculate` 只算尺寸、`Update` 套用），不使用 `TableLayoutPanel`，Designer 寫入橫式加工頁的計算結果 | R2、R5 |
| S13 | **置中**：`DialogPlacement` 一處計算，`DialogBase.OnLoad` 與 `FormBase.Show` 呼叫；CAM 區域由主視窗註冊 | R2 |
| S14 | **多語系**：控制項名稱即 ID、表單標題 ID 為類別名稱，由三個基底的 `ApplyLanguage` 經 `LanguageApplier` 套用，取代各畫面手寫的套用程式；共用按鈕文字集中於 `CommonUI_<語系>.xml` | R2 |
| S15 | **控制項白名單與命名**：畫面只用白名單型別，欄位名稱為「型別前綴 + PascalCase」，全域改名（309 筆），語系 ID 同步 | R2、R3 |
| S16 | **特例**：承載單一內容的視窗、`CNCInfoPanel` 直式改排列、資料色、`CNCThreePointDlg` 可為空的欄位、`ComboBox` 暫留、`ToolTip` 的用途，各有定義並登錄（指引「共識的特例」） | R3 |
| S17 | **檢查機制**：可持續使用的檢查放在 `Tools/UICheck`，規則以名稱識別；本議題限定的檢查放在 `Tests/`，基準固定為分支起點。檢查需要的狀態以反射呼叫產品既有方法觸發，runner 執行結束即從建置輸出刪除 | R6、R7 |
| S18 | **專案指引**：`ui-style.instructions.md` 只寫原則與共識的特例，`icon-design.instructions.md` 寫圖示的產生方式；數值、API 與規則細節由程式與註解說明。程式註解不引用文件內容或章節，出處只寫議題編號 | R7 |

## 2.3 相容性異動

以下項目都已決議接受，不需要修改程式；合併時寫入 Merge Request 說明，部署到有客製檔案的現場時告知。

### 輸入

| # | 異動 | 既有資料的處理 |
| --- | --- | --- |
| 1 | **語系 ID 改名與刪除**：ID 改為控制項名稱、控制項欄位依前綴改名，並刪除無用 ID；以 zh-TW 計，30 個語系檔共 173 個舊 ID 不再使用。客製語系檔（`Custom/Language`）以 ID 逐筆覆蓋標準語系，舊 ID 的客製文字失效，畫面改顯示標準文字，不會出錯 | 不再支援舊 ID（2026-11-15 決議）。有客製語系檔的現場，依 `git diff a4b3826d <合併 commit> -- Language/` 的新舊 ID 對照改寫客製檔 |
| 2 | **語系檔改名**：`LockABDlg_<語系>.xml` → `LockMSAxisDlg_<語系>.xml`、`CNCThreePointDialog_<語系>.xml` → `CNCThreePointDlg_<語系>.xml` | 舊檔名不再讀取；客製檔改為新檔名 |
| 3 | **共用按鈕文字改為全域**：26 個設定 `CommonText` 的按鈕（確定、取消、重設、預覽、關閉）一律讀 `CommonUI_<語系>.xml` 的 `Confirm`、`Cancel`、`Reset`、`Preview`、`Close`，不再讀畫面自己的 ID | 要保留的客製文字改寫到 `Custom/Language/CommonUI_<語系>.xml`；同一種按鈕的文字全畫面一致，不能再依畫面不同 |
| 4 | 機構、後處理、專案等其他設定與資料檔 | 無 |

### 輸出

無。NC 程式、專案檔與其他產出檔案的內容不變。

### 操作外觀（非資料相容性，合併說明時一併告知現場）

1. 對話框不可改大小、不出現在工作列（S2）。
2. 數值欄位改為數值框的細節差異：可用上下鍵與滾輪、小數位數固定、非法輸入回復合法值（S5）。
3. 只顯示的座標改為標籤後不能選取複製（S5）。
4. 橫式主視窗的警報在一般狀態位於日誌右側（S6）。
