# UI 風格統一：需求、決議與後續項目

> 議題：UI 風格盤點、優化、統一（分支 `AUTO-TBD_f_UIStyleUnify`，議題編號待補）
> 本檔記錄使用者提出的要求與討論後的決議，是本議題的唯一紀錄來源；設計內容見 [UIStyleDraft.md](UIStyleDraft.md)。
> 每次討論有新的要求或決議時，追加到對應章節，並標上日期。

## 1. 目標與原則

- 對現有 UI 做完整盤點，訂出分類規劃與風格，再全面重構。（2026-11-15）
- 現有 UI 只作為**操作規格**的參考；在操作語意不變的前提下，實作可以盡量重構。（2026-11-15）
- 除了外觀一致，**實作方式也要集中收斂**，避免不必要的實作風格分裂。（2026-11-15）
- 每一類 UI 要訂出建構規則：靜態時處理哪些事、動態時處理哪些事；能抽象共用的就共用，真的不行的再討論是否有必要分裂。（2026-11-15）

## 2. 規格限制

- 直式與橫式人機的解析度固定為 1920×1080，縮放 100%；可依此設計固定尺寸的控制項。（2026-11-15）
- 實際維護的語系只有 zh-TW、zh-CN；外觀檢查時這兩個語系顯示正常即算通過。（2026-11-15）
- 風格：淺色、現代、不失穩重。不需要主題切換，只做一套固定主題。（2026-11-15）
