# 1. 本議題目標說明

## 1.1 目標

在**操作行為沒有相容性異動**的前提下，盡可能重構 MyCAM 的操作外觀：

1. **外顯風格一致**：所有畫面使用同一套色票、字型、尺寸、元件與編排規則。
2. **底層實作一致**：同樣的外觀只有一種實作方式，集中在共用的基底與元件，不在各畫面各自處理。
3. **分類必要、分類內沒有例外**：只在真的需要不同處理的地方分類；同一分類內的項目一律依同一規則，沒有個別例外。

## 1.2 原則

- 現有 UI 只作為**操作規格**的參考；操作語意不變的前提下，實作可以盡量重構。
- 每一項改動都要先判斷是外觀還是行為。判斷標準：改動後，使用者能做的操作、操作的順序與結果、視窗是否強制回應，
  都必須和改動前一樣。行為差異一律不動，列入後續議題。
- 每一類 UI 訂出建構規則：靜態時（Designer、建構子）處理哪些事、動態時（執行時）處理哪些事；能抽象共用的就共用。
- **Designer 如實呈現**：保留 Designer 排版，Designer 看到的就是執行時的樣子。
- 產品程式不留任何為了檢查而寫的程式碼。

## 1.3 規格限制

| 項目 | 規格 |
| --- | --- |
| 解析度 | 直式與橫式人機皆為 1920×1080、縮放 100%（96 DPI），可依此設計固定尺寸 |
| 語系 | 程式支援 zh-TW、zh-CN、en-US、ru-RU；實際維護的是 zh-TW、zh-CN，外觀檢查以這兩個語系為準 |
| 主題 | 淺色、現代、不失穩重；只做一套固定主題，不需要主題切換 |
| 橫 / 直式判斷 | 依主視窗外框長寬比（高 > 寬為直式），與系統顯示方向無關 |
