description: 開始新議題時使用：盤點現況、建議分級、開分支、建立議題資料夾與 README.md。使用者說「開議題」、「開始議題」，或要開始處理新的 bug、功能時觸發。
---

依 `.github/process/issue-workflow.md` 執行，議題文件依 `.github/process/issue-docs.md` 撰寫，開分支依 `.github/process/git-workflow.md`。

必讀文件：

1. `.github/process/issue-workflow.md`
2. `.github/process/issue-docs.md`
3. `.github/process/git-workflow.md`
